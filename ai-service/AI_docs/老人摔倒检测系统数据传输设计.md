
# 老人摔倒检测系统——数据传输设计

本文档说明系统中 **不同类型数据的传输方式**，以及推荐的实现技术。

系统主要包含三类数据传输：

1. 视频流传输
2. 检测事件数据传输
3. 控制命令传输

---

# 一、视频流传输（实时监控画面）

## 1. 作用

用于将 **带检测框和标签的实时视频画面** 显示在：

- 后台管理系统（Vue）
- 手机 App
- 监控页面

例如画面中可以看到：

- 人体检测框
- 标签：fall（摔倒）
- 实时监控视频

---

## 2. 数据特点

| 特点 | 说明 |
|---|---|
| 数据量 | 非常大 |
| 传输频率 | 每秒约 20~30 帧 |
| 数据内容 | 图片 / 视频帧 |
| 延迟要求 | 低延迟 |

由于视频数据量很大，因此 **不适合使用普通 HTTP API 逐帧传输**。

---

## 3. 推荐技术方案

| 技术 | 说明 | 推荐程度 |
|---|---|---|
| RTSP | 常用于网络摄像头 | ⭐⭐⭐ |
| WebRTC | 超低延迟视频通信 | ⭐⭐⭐ |
| MJPEG | 实现简单，适合项目开发 | ⭐⭐ |
| HLS | 延迟较高 | ⭐ |

对于课程设计或原型系统，**MJPEG 是最简单可实现的方案**。

---

## 4. 视频流传输流程

```
摄像头
   ↓
Python AI检测程序
   ↓
视频流服务
   ↓
Vue前端 / 手机App
```

---

# 二、检测事件数据传输（摔倒报警信息）

## 1. 作用

当 AI 检测到 **老人摔倒** 时，需要将检测结果发送到后端系统，例如：

- 摔倒事件
- 发生时间
- 摄像头编号
- 置信度
- 截图

这些信息用于：

- 报警提示
- 数据记录
- 历史查询
- 数据分析

---

## 2. 数据特点

| 特点 | 说明 |
|---|---|
| 数据量 | 小 |
| 传输频率 | 低 |
| 数据格式 | JSON |
| 重要性 | 高 |

示例数据：

```json
{
  "cameraId": "living_room",
  "event": "fall",
  "time": "2026-03-15 20:30:10",
  "confidence": 0.93
}
```

---

## 3. 推荐传输方式

| 技术 | 用途 |
|---|---|
| HTTP API | 发送检测事件 |
| WebSocket | 实时报警推送 |
| MQTT | IoT设备通信 |

常见实现方式：

```
HTTP + WebSocket
```

---

## 4. 数据传输流程

```
Python AI检测
      ↓
HTTP POST 请求
      ↓
SpringBoot 后端
      ↓
数据库存储
      ↓
WebSocket 推送
      ↓
Vue / 手机 App 报警提示
```

---

# 三、控制命令传输（系统控制指令）

## 1. 作用

允许前端系统 **控制 AI 检测服务**，例如：

- 切换摄像头
- 切换检测模型
- 开始检测
- 停止检测

---

## 2. 数据特点

| 特点 | 说明 |
|---|---|
| 数据量 | 小 |
| 传输频率 | 低 |
| 数据格式 | JSON |

示例请求：

```json
{
 "cameraId": "cam02"
}
```

---

## 3. 推荐技术

| 技术 | 说明 |
|---|---|
| HTTP REST API | 实现简单、通用 |

---

## 4. 控制命令传输流程

```
前端 (Vue)
      ↓
SpringBoot 后端
      ↓
Python AI服务
```

示例接口：

```
POST /switch_model
POST /switch_camera
POST /start_detect
POST /stop_detect
```

---

# 四、系统整体数据流

```
            摄像头
               │
               ▼
        Python AI检测服务
        │              │
        │              │
        ▼              ▼
     视频流传输        检测事件
   (MJPEG / RTSP)       (HTTP)
        │               │
        ▼               ▼
      Vue前端        SpringBoot
                        │
                        ▼
                     数据库
                        │
                        ▼
                    WebSocket
                        │
                        ▼
                  Vue / App报警
```

---

# 五、数据类型总结

| 数据类型 | 内容 | 传输协议 | 示例 |
|---|---|---|---|
| 视频流 | 视频帧 | RTSP / MJPEG / WebRTC | 实时监控 |
| 检测事件 | JSON | HTTP | 摔倒报警 |
| 控制命令 | JSON | HTTP | 切换模型 / 摄像头 |

---

# 六、总结

系统通过 **三种不同的数据传输方式** 实现完整功能：

1. **视频流传输**：用于实时监控画面展示  
2. **检测事件传输**：用于记录摔倒事件并报警  
3. **控制命令传输**：用于前端控制 AI 服务  

这种架构可以实现：

- 实时视频监控
- 自动摔倒检测
- 实时报警通知
- 系统远程控制

同时也提高了系统的 **可扩展性、稳定性和性能**。
